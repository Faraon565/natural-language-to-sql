# Natural Language to SQL

Учебное приложение на Python для генерации SQL-запросов по текстовому описанию пользователя.

Пользователь формулирует запрос на обычном языке, после чего приложение передаёт структуру базы данных локальной языковой модели и получает SQL-запрос. Затем запрос выполняется, а результат отображается в виде таблицы и, при необходимости, графика.

## Основные возможности

- загрузка базы данных SQLite
- анализ структуры таблиц и полей
- генерация SQL-запросов по текстовому описанию
- выполнение сгенерированных запросов
- вывод результатов в таблице
- построение графиков на основе полученных данных
- повторная генерация запроса при возникновении ошибки
- работа через веб-интерфейс Streamlit

## Как работает приложение

1. Пользователь загружает SQLite-базу данных.
2. Приложение получает информацию о структуре таблиц.
3. Пользователь формулирует запрос на естественном языке.
4. Структура базы данных и текст запроса передаются локальной LLM.
5. Модель генерирует SQL-запрос.
6. Приложение выполняет запрос и показывает результат.
7. Если данные подходят для визуализации, строится график.

## Запуск проекта

Для работы приложения необходим Python и установленный Ollama.

Сначала установите зависимости:

```bash
pip install -r requirements.txt
```

Затем убедитесь, что Ollama установлен и модель `llama3` доступна локально.

После этого запустите приложение:

```bash
streamlit run app.py
```
